# Azərbaycan Kamera İdarəetmə Sistemi

Bu tətbiq Azərbaycanın müxtəlif şəhər və rayonlarındakı kameraların IP ünvanı və port məlumatlarını idarə etmək üçün yaradılmışdır.

## Xüsusiyyətlər

- 🏙️ **Şəhər və rayon seçimi** - Azərbaycanın əsas şəhərlərini və rayonlarını seçə bilərsiniz
- 📹 **Kamera axtarışı** - Çox sürətli kamera axtarışı
- 📊 **Real-time statistikalar** - Aktiv və deaktiv kameraların sayı
- 📋 **IP/Port kopyalama** - Sağ klik ilə IP və port məlumatlarını kopyalaya bilərsiniz
- 🎨 **Modern GUI** - Gözəl və istifadəçi dostu interfeys
- 🔍 **Detallı məlumatlar** - Hər kamera üçün ətraflı məlumatlar

## Quraşdırma

1. Python 3.6 və ya daha yuxarı versiyası tələb olunur
2. Tələb olunan paketləri quraşdırın:

```bash
pip install -r requirements.txt
```

## İstifadə

Tətbiqi işə salmaq üçün:

```bash
python azerbaijan_camera_manager.py
```

## İstifadə təlimatı

1. **Şəhər seçin** - Aşağı açılan siyahıdan şəhər seçin
2. **Rayon seçin** (istəyə görə) - Xüsusi rayon seçə bilərsiniz
3. **"Kamera Axtar" düyməsinə basın** - Kameraları axtarmağa başlayın
4. **Nəticələri görün** - Tapılan kameralar cədvəldə göstəriləcək
5. **Sağ klik** - IP/Port məlumatlarını kopyalamaq və ya ətraflı məlumatları görmək üçün
