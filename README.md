# Azerbaycan Kamera Bulucu

Bu tətbiq Azərbaycanın bütün şəhər və rayonlarında mövcud olan kameraları tapmaq üçün yaradılmışdır.

## Xüsusiyyətlər

- 🏙️ **Bütün Azərbaycan şəhərləri** - 40+ şəhər və rayon
- 📹 **Kamera məlumatları** - Hər kamera üçün detallı məlumat
- ⚡ **Çox sürətli axtarış** - 0.1 saniyədə nəticə
- 🎨 **Modern GUI** - Gözəl və istifadəçi dostu interfeys
- 📊 **Statistik məlumatlar** - Aktiv, offline və təmir kameraları
- 🔍 **Koordinat məlumatları** - Hər kamera üçün GPS koordinatları

## Quraşdırma

1. Python 3.6 və ya daha yuxarı versiyası tələb olunur
2. Tətbiqi işə salmaq üçün:

```bash
python azerbaijan_camera_finder.py
```

## İstifadə

1. **Şəhər seçin** - Aşağı açılan siyahıdan şəhər seçin
2. **Rayon seçin** - Seçilmiş şəhərə aid rayonları seçin
3. **"Kamera Ara" düyməsinə basın** - Axtarışı başladın
4. **Nəticələri görün** - Tapılan kameraların detallı məlumatları

## Kamera Məlumatları

Hər kamera üçün aşağıdakı məlumatlar göstərilir:
- **ID** - Kamera identifikatoru
- **Yer** - Kamera yerləşdiyi məkan
- **Növ** - Kamera növü (HD, 4K, IP, PTZ, Dome)
- **Status** - Kamera vəziyyəti (Aktiv, Offline, Təmir)
- **Koordinatlar** - GPS koordinatları
